# 🔮 LFG Teleport Button (Midnight Edition)

**Keep forgetting which dungeon you've been invited to?**  
**Stop fumbling through your spellbook.**  
**LFG Teleport Button** automatically creates  one-click teleport button whenever you're invited to a Mythic+ group.

---

### ✨ Features
- **Auto-Detect**: Instantly recognizes the dungeon you're invited to.
- **One-Click Port**: A big, obvious button appears right in the center of your screen.
- **M+ UI Integration**: Click dungeon icons directly in the Challenges frame to teleport!
- **Smart Tooltips**: Shows spell name, cooldown status, or "Not Known" in M+ UI.
- **Smart**: Hides automatically after you cast the teleport spell.
- **Movable**: Hold CTRL and drag the button to reposition it.
- **Ready for Midnight**: Fully updated for **Season 1** dungeons!

### 🏰 Supported Dungeons (Season 1)
1. **Windrunner Spire**
2. **Skyreach**
3. **Seat of the Triumvirate**
4. **Pit of Saron**
5. **Nexus-Point Xenas**
6. **Maisara Caverns**
7. **Magisters' Terrace**
8. **Al'gethar Academy**

### 🚀 How to Use

**LFG Invite Button:**
1. Apply for a dungeon in Group Finder.
2. Get invited and accept.
3. Click the button that pops up to teleport!

**M+ UI Overlay:**
1. Open the Mythic+ Dungeon UI (Challenges frame).
2. Click any dungeon icon to teleport directly!
3. Hover to see spell status (Ready / Cooldown / Not Known).

### 🛠️ Commands
- `/tpbutton test N` : Test the button (N = 1-8)
- `/tpbutton debug` : Show dungeon and spell info
- `/tpbutton reset` : Reset button position to center
- `/tpbutton state` : Show current button state

### 💡 Tips
- **CTRL + Left-Drag**: Move the teleport button
- **ALT + Right-Click**: Dismiss the button
